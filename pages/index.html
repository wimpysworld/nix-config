Nix Config

Martin Wimpress's Nix Flake for managing Linux workstations, servers, virtual machines, live ISO images, and macOS from one repository.

Read the overview Daily ISO builds

Broadcast-and-gate architecture

Every host imports every module, and each self-gating module activates from typed host metadata in the noughty module system. Starting your own Nix configuration? Try nix-starter-configs first.

Architecture

One flake, every system

Host directories hold only hardware layouts and kernel modules. Shared behaviour activates from host properties in the system registry.

01 Self-gating modules
Drop a module under _mixins and gate it with config.noughty.* metadata. No per-host import lists to maintain.
02 Cross-platform fleet
Manages NixOS desktops with Wayfire and Mango, laptops, servers, virtual machines, a live installer ISO, macOS via nix-darwin, and Home Manager.
03 FlakeHub Cache fast path
CI builds every configuration on push to main and publishes closures to FlakeHub Cache for direct fetch and activation.
