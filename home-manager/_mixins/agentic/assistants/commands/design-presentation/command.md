# Design presentation

Load `marp-presentations` to create or revise the deck.
Use `$ARGUMENTS` as the brief or deck path, or the accompanying user text on Codex. If blank, ask for either.
Apply the skill end-to-end, from deck plan through authoring, rendering, inspection, revision, and delivery. Do not duplicate its guidance here.
This workflow writes Markdown, theme copies, assets, and exports in the approved output directory.
It runs the skill's `scripts/export.py` through `python3`, plus `marp` and browser rendering as required.
