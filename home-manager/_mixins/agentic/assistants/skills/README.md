# Assistant skills

Generated from validated metadata. Run `just update-assistant-catalogue` to update this file.

These tables describe repository sources and projected client metadata, not installed resources or runtime authority. Client enablement still applies. No metadata override means that this source sets no listed control, not that all tools are allowed.

Only top-level skills are listed. Nested reference files are not separate entries. Generated delegate-task uses public metadata without reading its body. Secret bodies include their own metadata, so their descriptions and policies are unknown here. Workspace skills require both a developer user and a cg host, in addition to client enablement.
