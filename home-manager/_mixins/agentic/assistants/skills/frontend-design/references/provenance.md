## Local policy

The adaptation preserves the brief, established brand, and project design system rather than imposing a new identity.
It treats labels and decoration as information devices, not a mandatory visual pattern or a blanket prohibition.
It does not import upstream font bans, concept lotteries, confirmation loops, persistent critique storage, browser overlays, or agent dispatch.
It imports no binary launchers, scripts, package manifests, installers, native-platform guidance, or upstream runtime dependencies.
The temporary page-trial supplement is not a source for this integration.

The delivery gate is stricter than the upstream conditional screenshot guidance.
Advice remains possible without a browser, but created pages remain unverified and not review-ready until the gate passes.
