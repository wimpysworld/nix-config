## Draft Comment

Load the `draft-comment` skill and run its read-only drafting flow.

Target argument: $ARGUMENTS. This is the thread URL, optionally followed by the angle or point the user wants to make. If $ARGUMENTS is blank, ask which thread and wait.

Apply `draft-comment` end-to-end: target resolution, provider reads, contribution voice, read-only boundary, cut pass, and fenced verbatim output. Do not duplicate that guidance here.
